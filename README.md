# HANDLER

> **你只能下令，不能操作他们。**
> 实时战术肉鸽 —— 你不在战场上，你在一副耳机和一张被雾吃掉的地图后面。

---

## 这是什么

一款**指挥向**的战术肉鸽（Godot 4.7 / 全程序化美术与音效）。

- 你指挥的是**编队**，不是单台机甲。编队自己打，你只负责：**打谁、往哪走、什么姿态、点亮哪里**。
- 命令有**延迟**（1.5~3.5 秒）和**执行率**（他们可能听懂了，也可能没听懂）。
- 战场是黑的。**雾里什么都不画**，雾外全部完整渲染。
- 肉鸽：固定战役流程、可选分支、永久死亡、跨局累计的敌意。

**视觉与战场语言的唯一参考**：《Usurper 篡夺者》（IndieRaven）——
深蓝黑底、发光几何体、长拖尾、大面积留黑。

## 怎么跑

### 方式一：双击 `启动游戏.bat`（推荐）

```
set "GODOT=D:\Godot\Godot_v4.7.2-stable_win64.exe"
```
如果 Godot 不在这个路径，用记事本改这一行。

### 方式二：用 Godot 编辑器

1. 打开 `D:\Godot\Godot_v4.7.2-stable_win64.exe`
2. Import → 选本文件夹的 `project.godot` → Import & Edit
3. F5

> 需要支持 Vulkan 的显卡（用了 Forward+ 的 HDR 2D 泛光）。
> 起不来就把 `project.godot` 里 `renderer/rendering_method` 改成 `gl_compatibility`，会失去辉光。

## 操作

| 输入 | 作用 |
|---|---|
| `WASD` | 平移镜头 |
| `滚轮` | 缩放（0.95x ~ 3.4x） |
| `1` `2` `3` / `Tab` | 选中编队 |
| **左键点编队** | 选中 |
| **左键点敌人** | 集火（需要看得见） |
| **左键点地面** | 下达移动命令 |
| **右键** | 点亮一片迷雾（CD 10 秒，标记敌人 25 秒） |
| `Q` | 循环切换姿态：进攻 / 固守 / 机动 / 撤离 |
| `E` | 循环切换交战规则：最近 / 最危险 / 只打视野内 / 保命优先 |
| `F1`~`F9` | 使用卡牌 |
| `空格` | 暂停 |
| `Esc` | 取消 / 菜单 |

## 已经做进去的系统

### 指挥
- **命令在途**：下令后 1.5~3.5 秒才生效，编队按执行率决定听不听。
  面板上那条金色细线就是在途进度——**它在走，就代表你已经做了你能做的**。
- **执行率** = `30 + 0.5×信任 + 注意力修正`，随编队数量下降（你只有一个脑袋）。
- **姿态 × 交战规则**：4×4，全部改行为树，不加系数。
- **崩溃**：完整性归零 → 编队自己往回跑、不听命令 → 30 秒内可「收容」。

### 情报
- **四层视野**：本体扇形视觉 / 方位楔预警 / 右键脉冲 / 侦察型记忆（45 秒，会褪色）。
- **雾里什么都不画**；雾外完整渲染（地形、敌人、拖尾、弹道、爆炸）。
- **标记**：我方对被标记目标伤害 ×1.4，并且能集火。
- **偷袭**：没被发现的敌人第一击 ×2.0，并让编队「措手不及」2 秒。

### 角色
- **特殊机师**（5 名，唯一）：服从面 = 有形状的工具，用对了是神，用错了害死你。
- **普通机师**（8 种机体配置，可重复）：近接 / 射击 / 狙击 / 压制 / 重装 / 侦察 / 电子战 / 指挥。
- **没有战场维修**：这一仗挨的打，得回后方修。

### 肉鸽
- 固定战役 10 个节点、3 段战线、1 个 BOSS（牧羊人），**分支可选**。
- 探索拿卡牌、休整招人/整备/拆队、战后三选一。
- **永久死亡**：阵亡的机师进 MEMORIAL，名字不回收。
- **大脑回收**：人死了脑髓还在，45 秒内派人去抢；抢不到，军团会把他做成「回响」回来打你。
- 压力值：拖时间、深入搜索都会涨，满 100 战役失败。

## 已知限制

- 只有 1 个战役、10 个节点、7 种敌人、10 张卡，**没有跨局元进度**（下一局从零开始）。
- 地形只有视觉与移动修正，**没有实现遮挡视线**（城区还是靠感觉）。
- 敌方 AI 是「找最近 + 推进 + 开火」，没有包抄寻路；「四面合围」目前靠刷怪方位。
- 平衡只跑过自动脚本，真人手感待调。
- 编辑器未使用，场景全部代码生成。
