## 0. 这份文档是什么

把「86 视角 + 自走棋 + 战争迷雾 + 战略肉鸽」这套想法整理成一份可执行的设计。

- 所有数值都是**起点值**，标了 `[待调]` 的说明它必须靠试玩改。
- **不照搬 86 的"管制官看不见"设定。** 玩家能看见整片战场——**只要那里没有迷雾**。雾外的地形、己方、敌方、拖尾、弹道、爆炸，全部完整渲染。
  我们借的是蕾娜的**处境**（只能下令），不是她的**视觉限制**。
- 术语沿用 86 语境（管制官 / 编队 / 军团 / 破坏神 / 共感 / 帕拉瑞德）。若要转成原创 IP，见**附录 C** 的替换表，删掉括号里的词即可。
- **美术 / 战场 / 敌人表现的唯一参考标准**：《Usurper 篡夺者》（IndieRaven）。
  参考视频：<https://www.bilibili.com/video/BV1V5x16DEnw/>
  只参考它的**画面语言**，不参考它的玩法——**玩法是我们自己的战略肉鸽**。
- 除此之外，不参考任何现成项目。

## 1. 一句话、核心循环与设计支柱

**一句话：你从一个只能盯着一个人的管制官，长成一个不得不放弃某一翼的指挥官。**

### 1.1 核心循环：指挥

这游戏只有一件事可做：

> **判断该把哪条命令，送给哪个人，在什么时间点。**

```
1. 观察   方位楔在哪亮？编队现在什么姿态？谁快撑不住了？
2. 判断   哪边最危险？要不要分兵？要不要放弃一边？
3. 下令   打谁 / 往哪走 / 什么姿态 / 点亮哪里
4. 等待   命令在途 1.5~3.5 秒，编队按自己的理解执行
5. 承担   它做到了 / 它理解错了 / 它根本没听
6. 归因   战后告诉你：是你的命令、你的情报，还是它自己的判断
```

**光是这个循环里"观察"那一步的工具之一，不是玩法本身。**

玩家能做的事只有两类：

| 类别 | 具体动作 |
|---|---|
| **指挥** | 集火、移动、改姿态、改交战规则、用卡牌 |
| **提供信息** | 点亮、标记、侦察型部署、情报卡 |

**这两类加起来就是全部。没有第三个动词。**

### 1.2 九条铁律

任何功能、任何卡牌、任何数值，违反其中一条就砍掉：

| # | 铁律 | 推论 |
|---|---|---|
| 1 | **你只能下令，不能操作** | 编队自主执行；结果必须可预览、可归因 |
| 2 | **你提供的是信息，不是手** | 点亮、标记、侦察、情报卡，都是在"喂"编队 |
| 3 | **光是共享知识，不是玩家专属 UI** | 点亮后，该区域的编队 AI 也"知道"了 |
| 4 | **光的价值是反应时间，不是伤害系数** | 发现 = 能转向、能开火、能找掩体 |
| 5 | **姿态改行为树，不改系数** | 永远不做「+30% 防御」 |
| 6 | **卡牌必须有代价，且姿态做不到** | 纯增益牌 = 设计失败 |
| 7 | **名字是方位，功能是算出来的** | 中央/左翼/右翼是坐标，不是职业 |
| 8 | **上限钉死：3 编队 / 10 人 / 12 张牌** | 后期不靠数值成长，靠"指挥得更准" |
| 9 | **每个结果都必须能归因；迷雾里没有敌人** | 战后必须说清"是谁杀了他"；没看见的一个字都不画 |

## 2. 乐趣假设

设计文档最容易失败的地方，是写满了系统却没写"哪里好玩"。这是本作的五条乐趣来源，以及怎么验证它们。

### 2.1 五个快感

| # | 快感 | 机制来源 | 如果它不成立 |
|---|---|---|---|
| A | **被服从 / 被误解** | 下令 → 2.5 秒后他们做了，或者没做你想的 | 游戏没有核心动作，重做 |
| B | **来不及** | 命令还在路上，人已经死了 | 游戏变成回合制 |
| C | **揭晓** | 点亮黑暗，看清里面是什么 | 决策没有依据，变成盲赌 |
| D | **守住了** | 编队崩溃但没死，收容成功 | 挫败感压过成就感 |
| E | **长成了** | 从 1 人到 3 编队 | 游戏没有形状 |

> **A 是主菜，B 是它的调料。**
> C 不是菜，是**上菜之前那口气**——它让每一次下令都需要勇气。

### 2.2 验证方式

**MVP 只验证 A 和 B。**

- **A 的验证**：玩家下完令，会不会**盯着那个编队等结果**？等到了之后，会不会**骂一句**？
  既不等也不骂，说明命令没有重量——去调执行率和延迟，不要再加系统。
- **B 的验证**：命令在途的那 2.5 秒，玩家会不会**不自觉地屏住呼吸**？
- C 的验证（次要）：玩过的人会不会主动、高频地点亮？只在被打时才点，说明"投资型点亮"没做出来。
- 最朴素的验收：找 5 个人玩 15 分钟，问一句——**"你刚才最想骂人的是哪一秒？"** 五个人说的应该是同一秒。

## 3. 美术与战场语言

### 3.1 视觉基因（来自 Usurper）

> **参考的是画面，不是玩法。**
>
> **拿它的**：深蓝黑底、发光几何体、长拖尾、加法辉光、大面积留黑、俯视镜头感。
> **不拿它的**：增量射击、夺取敌舰、弹幕闪避、单角色操作。
>
> **玩法是第 1、5–17 节写的那套战略肉鸽，与它无关。**

参考视频：<https://www.bilibili.com/video/BV1V5x16DEnw/>

参考画面里有四样东西，必须全拿到：

1. **深蓝黑底 + 极淡网格**——网格提供尺度感和坐标感，透明度要低到几乎看不见，只在辉光边缘被"照亮"时才浮现。
2. **发光的实心几何体 + 高饱和描边**——我方是白青色，敌方是橙红色，都是低填充 + 亮描边。
3. **长拖尾**——**这是"铺天盖地"的唯一来源。** 一个红三角是一个点；一条红线是一条威胁；五十条红线才是一场洪水。
4. **大面积留黑**——参考图里将近一半的屏幕什么都没有，不要怕空。
   **在我们的游戏里，这块黑就是迷雾。** 所以它不是"构图的留白"，是"设定的一部分"：黑的部分你什么都看不见，亮的部分你全看得见。

**一句话的画面公式：一半是正在烧的战场，一半是什么都没有的黑，交界上浮着几道弧。**

### 3.2 色板与形状

| 元素 | 形状 | 颜色 | 说明 |
|---|---|---|---|
| 我方单位 | 三角（尖端=朝向） | `#DFF6FF` 白青 | 描边 2px + 辉光；拖尾 6~10 体长 |
| 敌方单位 | 方块 | `#FF3B30` → `#FF7A2E` | **一台 = 一个方块**；雾外才出现 |
| 已标记敌方 | 实心方块 + 四角括线 | 内部加 `#FFD166` 图标 | 标记 = 你知道它是什么 |
| **方位提示** | **弧形楔（无填充、无实体）** | `#FF5A3C`，α 0.25~0.70 | **迷雾里唯一会出现的"敌方"**：只有方向，没有敌人 |
| 记忆残影 | 小十字 | `#FF7A2E`，α 0.35 | 你最后看到它的位置，不是它现在的位置 |
| 设施 / 目标 | 圆 | `#3DDC97` 青绿 | |
| 地形区 | 六边形 | `#0E1A28`，α 0.25 | 城区 / 山区 / 平原 |
| 可交互物 | 菱形 | `#FFD166` 琥珀 | 废墟 / 补给箱 / 探索点 |
| 重要标记 | 十字 | `#FFFFFF`，α 0.6 | 玩家手动标注的优先目标 |
| 情报亮区 | 软圆 | `#4FC3F7`，α 0.12 | 点亮后的区域 |
| 侦察标记 | 软圆 + 边界细线 | `#7FE3FF`，α 0.08 → 0 | **45 秒**，越走越暗 |
| 弹道 | 细线 | 白 | 存活时间 0.08~0.15 秒 |

**只允许七种形状**（三角/方块/圆/六边形/菱形/十字/线）。形状少，识别才快；识别快，黑暗才可读。

### 3.3 雾外全看得见，雾里什么都没有

这是本作最重要的一条视觉规则，两头都必须做满：

> **雾里：不是"看不清的敌人"，是"什么都没有"。一个字都不画。**
> **雾外：地形、我方、敌方、拖尾、弹道、爆炸——全部正常渲染，做到参考视频的密度。**
> **越亮 = 你越确定。** 半透明 = 不确定。虚线 = 已过期。

于是玩家的视觉体验是一条认知梯度：

```
黑（雾里，什么都没有）
  ↓  ← 方位提示：有东西，在那边，但不知道是什么
弧形楔（方向、粗略距离、大概数量）
  ↓  ← 脉冲点亮 / 侦察标记 / 编队走过
实体方块（看见了，知道它是什么）
  ↓  ← 标记
括线方块（记住了，能集火）
```

**迷雾不是一层滤镜，是一套信息语法。**

玩家必须永远能分清两件事：
- "我不知道那里有什么"（黑）
- "那里确实什么都没有"（也是黑）

这两件事在屏幕上**是同一个画面**——这就是恐怖片不给你看怪物的原因。

**而反过来的那一半同样重要：雾的边界上，应该是一片正在开火的战场。**
**所有"如何让你知道外面有东西"的活儿，交给方位提示和声音，不交给画面。**

### 3.4 画面的主体：雾外那一片正在打的仗

参考视频里最好看的东西，从来不是"看不见"，是**看得见的时候有多挤**。

> **你看到的是"已经冲进来的"；你看不到的是"还没冲进来的"。**

所以画面必须两头都做满。

**可见区（通常占屏幕 30~50%）——这里就是 Usurper**
- **我方**：三角，长拖尾，朝向清晰，开火有炮口焰，受击有火花，被击毁有环形冲击波。
- **敌方**：方块，红橙渐变，密集、流动、像潮水。**一台 = 一个方块，不是抽象编队。**
- **弹道**：白线，0.1 秒消失；命中：小火花 + 轻微震动。
- **密度标准：如果可见区看起来像"一场小规模交火"，就失败了。** 它必须像"被淹了"。

**不可见区（通常占屏幕 50~70%）——纯黑**
- 什么都不画。只有方位楔。
- **雾的作用不只是藏东西，是把可见区框起来**，让它显得又小又挤。

| 阶段 | 可见区内军团台数 | 全场台数 |
|---|---|---|
| 一 | 2~5 | 3~6 |
| 二 | 8~20 | 8~20 |
| 三 | 25~45 | 25~60 |
| 高潮围剿 | 40~60 | 80~150 |

视野内同时可见 ≤60 个方块（小尺寸：边长 10~14px，描边 2~3px）。

**"铺天盖地"的正确来源：不是雾里有一千台，是你在视野里看见四十台，而边界还在涌进来。**

配套三条：
- **拖尾密度**随台数上升，不要只放大方块。**拖尾是这个游戏的画面签名。**
- 远处**低频轰鸣**，音量 ∝ 附近军团数量——**声音是唯一能穿透迷雾的东西**。
- 军团移动要"像水"：整体流向 + 个体抖动。

### 3.5 HUD

- **左上**：编队列表（最多 3 格）。每格 = 方位名 / 功能读数 / 机体数 / 状态灯 / 注意力份额。
- **编队格上方一条细线**：**命令在途进度**——这是全游戏最重要的一个 UI 元素。它在走，就代表"你已经做了你能做的"。
- **右上**：压力条（0~100）+ 战役目标。
- **底部左**：无线电波形条——每个活着的单位一条，颜色 = 状态。**死亡时波形拉平、变成噪声、永远留在那。**
- **底部右**：卡牌栏（当前手牌）+ 指令点。
- **鼠标悬停编队**：显示执行率、方位提示范围、功能推导。
- 所有数字用**等宽小字号**。不要大号伤害数字——那是自走棋，不是指挥官。

### 3.6 镜头

- `WASD` 平移，`滚轮` 缩放，`鼠标边缘` 也可推镜头（可选）。
- 缩放范围 **0.35x ~ 2.0x**，带惯性。
- **缩放不改变"哪块可见"，只改变"看得多细"**：

| 倍率 | 看到什么 | 名字 |
|---|---|---|
| 0.35x | 可见区就是一片沸腾的色块（拖尾连成光带），雾区纯黑，边缘一圈方位楔 | **战役图** |
| 1.0x | 编队轮廓、朝向、状态灯、地形、可见的敌人 | **战术图** |
| 2.0x | 个体朝向、血量、通讯波形、拖尾细节 | **目视图** |

- **标记穿透缩放**：因为标记是"你知道过"，不是"你正在看"。
- 拉到最远时的画面应该是：**几块正在沸腾的亮色区域（拖尾连成一片光），被大片纯黑包住，黑与亮的交界上浮着几道红色弧。**
  亮的地方越亮，黑的地方就越黑——这才叫战争迷雾。
- 拉到最近（2.0x）时必须能看清个体：一个三角在转身，一台方块在推进，弹道从中间穿过去。
  **这个距离是给"看"用的，不给"算"用的。**

### 3.7 输入映射

| 输入 | 作用 |
|---|---|
| `WASD` / 鼠标推边 | 平移镜头 |
| `滚轮` | 缩放 0.35x ~ 2.0x，带惯性 |
| `1` ~ `3` | 选中编队 |
| 左键 · 点编队 | 选中 |
| 左键 · 选中后点敌人 | 集火 / 标注优先目标 |
| 左键 · 选中后点地面 | 移动方向 |
| `Q` | 切换姿态（循环） |
| `E` | 切换交战规则（循环） |
| `右键` | 脉冲点亮（全局，不需要选中编队） |
| `Tab` | 切换焦点编队 |
| `空格` | 暂停 |
| `Esc` | 取消 / 菜单 |

**只有四个常规动词：打谁、往哪走、什么姿态、点亮。**

**关于暂停：允许无限次暂停，且暂停时时间完全停止（包括命令在途与 CD）。**
这条明确了一件事——**这不是手速游戏**。紧张感来自"延迟和黑暗"，不来自"你点得够不够快"。

## 4. 一局的长相

```
一局 = 一个战役（60~75 分钟）
├─ 3 段战线
├─ 8~12 场遭遇（每场 3~8 分钟）
├─ 6~8 个探索点
├─ 3~4 个休整点
└─ 1 个战役高潮（大围剿 / 守点 / 突围 / 斩首）
```

**失败 = 战役失败，不是游戏结束。** 你可以带残部撤到撤离区，保住人，丢掉战役目标。

**时间线：**

| 阶段 | 时间 | 编队 | 破坏神 | 机师 | 注意力池 |
|---|---|---|---|---|---|
| 一 | 0~15 分 | 1 | 1~2 | 1~2 | 4 |
| 二 | 15~40 分 | 2 | 3~6 | 3~6 | 7 |
| 三 | 40~75 分 | 3 | 7~9 | 7~10 | 10 |

## 5. 视野与预警：四层系统

### 5.1 四层

| 层 | 来源 | 形状 | 范围 | 持续 | 给你什么 | 会标记吗 |
|---|---|---|---|---|---|---|
| **本体视觉** | 每个成员自带 | **扇形 140° + 近身圈 360°** | 5 格 / 2 格 | 持续 | 看见 | 否 |
| **方位提示** | 编队被动探测 | **弧形楔** | 11~15 格 | 持续（有延迟） | **只知道方向** | 否 |
| **脉冲点亮** | 鼠标右键（CD 10s） | 圆 | 4~7 格 | 6 秒 | 看见 + 标记 | **是**（期间进入者） |
| **侦察标记** | 侦察型经过 | 带 | 半径 4 格/点 | **45 秒** | 看见 + 标记 | **是**（进入即抓） |

前两层是**被动**的（你不做也有）；后两层是**主动**的（你要花东西换）。

**关键：四层全部是"共享知识"。** 点亮的区域不只是玩家看见——该区域内的编队 AI 也获得完整信息，会提前转向、提前开火、提前找掩体。

这就是"你负责提供信息"的落地方式：**你不是在给自己开视野，你是在给编队喂情报。**

**渲染规则（一句话）：**

> **被视觉覆盖的地方，全部完整渲染——敌人、朝向、拖尾、弹道、爆炸，一个不少。**
> **只有方位提示不画任何东西，它只画一道弧。**

也就是说，"能不能看见"和"能不能看见得清楚"是两件事：
- 看得见 → 全渲染，你可以盯着它打。
- 看不见但听得到 → 只有一道弧，你知道那边有东西。
- 看不见也听不到 → 黑。你什么都不知道。

### 5.2 方位提示：听得见，但看不见

编队有一台被动探测器。它不会告诉你那里有什么——它只告诉你三件事：

> **那个方向有东西。大概这么近。大概这么多。**

表现形式：编队外围画一段**发光的弧形楔**。没有填充、没有实体、没有任何"敌人的形状"。

| 属性 | 对应 | 传达 |
|---|---|---|
| 弧的**位置** | 方位角 | 大概从哪来 |
| 弧的**宽度** | 精度 | 窄 = 方向确定；宽 = 一片模糊 |
| 弧的**亮度** | 距离 | 越亮越近 |
| 弧的**抖动** | 数量 | 越抖越多 |
| 弧的**断裂** | 地形遮挡 | 被山/建筑挡住的方位更碎 |

**规则（每一条都在制造恐怖）：**

1. **不显示任何敌人实体**，不显示兵种，不显示精确位置。
2. 出现有 **1~2 秒延迟**——你先听见，然后才反应过来。
3. **敌人静止不动时，提示会衰减甚至消失。**
   > **"它停了"是这个游戏最恐怖的状态。**
4. **电子战型会制造假楔**——一个方向亮着，那边其实什么都没有。
5. **潜行型完全不产生提示**——连弧都没有，然后它出现了。
6. 编队崩溃 / 通讯中断时提示也消失：**你连"那边有东西"都不知道了。**

**精度公式：**

```
楔角宽   = 70° - 感知 × 8°      （感知 2 → 54°；感知 5 → 30°）
探测半径 = 扇形半径 × 2.2        （约 11~15 格）
```

于是侦察型有了第二个用途：**它让预警更准，而不只是看得更远。**

### 5.3 两套系统，一件事

> **方位提示 = 听到**（能预判、能躲、能提前布姿态，但打不了）
> **视野 = 看见**（能打、能标记、能集火）

这个分离，把右键点亮的意义变得极纯：

> **把"有东西"变成"是什么"。**

于是玩家的每一次点亮都是同一个仪式：
**看到弧变亮 → 犹豫 → 点亮 → 里面是 20 个方块 → 后悔。**

### 5.4 扇形视觉（重要）

视觉是**扇形**，不是圆形。理由：

- 它让"朝向"成为真实机制——被从背后摸进来是必然会发生的事。
- 它让"转向"成为一条可下的命令。
- 它让三角形的尖头有了战术含义。

每个单位 = `扇形(140°, 5格)` + `近身圈(2格)`。**被任一层覆盖 = 已发现。**

**侦察属性：**
- 每点 +0.6 格扇形半径，+8° 扇形角。
- 基础侦察 2 → 5.2 格 / 156°
- 侦察型 5 → 6.8 格 / 180°

**编队视野 = 所有成员的并集。** 所以你把侦察型放在哪个编队，光就在哪。

### 5.5 脉冲点亮（右键）

- **CD 10 秒**，全局共享。
- **射程不限，但半径随距离衰减**：距最近编队 ≤10 格 → 半径 7 格；每远 10 格 -1 格，最低 4 格。
- 照明 6 秒；这 6 秒内那片区域**被当作"看得见"处理**——敌人完整渲染，并且被标记；期间进入的敌人同样被标记。
- 设定解释：这是**你请求的一次雷达脉冲 / 让编队打出去的一发照明弹**，不是地图工具。

**点亮的取舍**：你永远在花一次 CD，去回答一个你**不想知道答案**的问题。

### 5.6 侦察标记（会过期的记忆）

侦察型是唯一能把黑暗**写进地图**的机体，但那张地图**会褪色**。

- 侦察型经过的格子，被写入"记忆"状态，**持续 45 秒**后重新变回迷雾。
- **重走可以刷新**——它跑回去一趟，那块记忆就再活 45 秒。
- 记忆中：敌人可见、可标记，编队 AI 共享该区域信息。
- **视觉上从离开那一刻开始线性变暗**，最后 5 秒闪烁，提示"这里要黑了"。
- 军团**电子战型**可以让一块记忆区**提前清零**（这是它最讨厌的一招）。

于是侦察型的价值不是"一次性画地图"，而是：

> **它决定了你能记住多久。**

而"记住多久"直接决定了你的纵深：记忆越短，你的战场就越窄，越像被黑暗压着打。

> **别和"敌人标记"搞混：**
> **区域记忆 45 秒** = 你看得见这块地。
> **敌人标记 25 秒** = 你知道这台是什么、能集火、打它更疼。

### 5.7 迷雾的恢复

迷雾**渐隐**，不是瞬断：

- 普通视野：离开后 5 秒内线性淡出。
- 侦察记忆：45 秒内线性变暗，最后 5 秒闪烁。
- 淡出过程中，最后一次看到的敌人位置留下一个"记忆残影"（**小十字**，2 秒后消失）。

这是最便宜的紧张感制造机——你会看见一个正在消失的方块，然后猜它是真的走了，还是正在靠近。

### 5.8 地形：影响视线，不影响数值

| 地形 | 视觉 | 视野影响 | 移动 | 战斗 |
|---|---|---|---|---|
| **平原** | 极淡网格 + 稀疏草点 | 正常 | 正常 | — |
| **城区** | 密集六边形块 + 暗街道 | **建筑切断扇形**；街道形成"走廊视野" | -20% | 掩体多，固守极强，最易遭伏 |
| **山区** | 等高线 + 高地光边 | 高地：半径 +3 格，但**低地是盲区**；低地：半径 -2 格 | 上下坡 -40% | 高地射程 +1 |
| **废墟** | 零星光点 + 缓烟 | 正常 | -10% | **可搜索**（舔包） |
| **水系**（可选） | 深色反光 | — | 不可通行 | — |

**关键：地形影响的是"你能看见什么"，不是"你多能打"。**
只有高地的 +1 射程是数值，其余全是视野与移动。

城区是这张图上的"迷宫"：街道给你长而窄的视野，建筑给你盲区。**偷袭和拦截几乎都发生在城区。**

## 6. 信息即战力

### 6.1 标记（Mark）

被标记的敌人：

| 效果 | 数值 |
|---|---|
| 我方对其伤害 | **×1.4** |
| 显示兵种图标 | 未标记时**所有敌人都是同一种方块** |
| 可被集火 | 未标记时编队只能打射程内的自主目标 |
| 攻击预警 | 起手 0.4 秒可被看见 |

**"未标记 = 一种方块"是本作的核心信息设计。** 你盯着一片一模一样的方块，不知道里面混着三台重炮、一台运输车、还是一群炮灰——直到你打一发光过去。

迷雾从"看不见"升级成"**看不懂**"。

### 6.2 偷袭（Ambush）

一个敌人如果在**第一次攻击前**没有被任何编队成员感知到：

- 该次伤害 **×2.0**
- 被攻击的编队获得「措手不及」2 秒：**不能转向、不能改姿态、不能开火**

这条取代了"未标记就 +X% 承伤"的粗暴设计。它带来的不是数字，是**两秒的无力**——那两秒里你什么都做不了，只能看着血条掉。

> **注意：方位提示不算"已发现"。**
> 你可以一边看着那个方向的弧在变亮，一边被人从背后偷袭。
> **"我知道那边有东西"和"我知道那是什么"之间，隔着一次点亮。**

### 6.3 侧后受击

攻击来自编队朝向反方向的 120° 扇区 → 伤害 **×1.2**。

让"朝向"值得管理，但不要做成主要机制。

### 6.4 三个乘法器的合计上限

`偷袭 ×2.0 × 标记 1.0（未标记）× 侧后 ×1.2 = ×2.4`

单次最高约 2.4 倍。**不要叠加更多乘法器。** 一旦超过 3 倍，玩家会觉得"死得莫名其妙"，归因就崩了。

## 7. 编队：唯一操作单位

### 7.1 铁律

> **编队是唯一可操作单位，人不是。**
> 你永远不点单个破坏神，只给编队下令；人在编队内部自己打。

### 7.2 结构

- 编队 1~3 台破坏神，**上限 3 个编队**。
- **一台破坏神 = 一名机师。** 机体是统一型号，差异来自兵装与机师。
- 名册上限 10（满编 9 + 1 替补）。
- **每队同配置普通机师最多 2 名；特殊机师每队最多 1 名。**（见 12.4）
- **每个编队有一个朝向**（朝向 = 队长的朝向）。
- 编队成员决定功能读数：**你放几个侦察型，这队就有多瞎或多亮。**

### 7.3 功能是算出来的，不是设的

```
火力 = Σ(输出属性) × 姿态系数
感知 = Σ(侦察属性)        → 决定该编队的视野半径
韧性 = Σ(防御属性)
机动 = 平均移速
主导功能 = 四项里最高的那个
```

UI 上并列两个标签：

> **左翼 · 当前功能：拦截**
> （方位固定；功能用颜色+图标，允许一场战役里变两次）

**每个编队要有 hover 面板回答"为什么"**：`3 人侦察属性 → 感知 78 → 主导功能：侦察`。

### 7.4 方位 → 压力 → 功能

**环形战场上，谁站中心，谁就四面受敌。**

- 中心：四面受敌，但可以向任何方向机动。
- 边缘：只需守 180°，但退无可退。

所以玩家最深的一层决策不是"给三个队派什么活"，而是：

> **把谁放在会被压死的位置上。**

把 Undertaker 放中央 → 他扛正面，而且他不听撤退令，正好。
把他放左翼 → 那一翼变成高杀伤但不听话的骚扰点，出事没人管得住。

### 7.5 拆分与合并

- **拆分：免费，CD 10 秒，有 3 秒过程**（期间两个新编队各只有 50% 战力）。
- **合并：卡牌「合流」**，不是免费动作。

这个不对称是有意义的：**分开容易，重新集结难。**

### 7.6 崩溃（≠ 死亡）

编队完整性（Integrity）0~100：

- 掉到 0 → **崩溃**：编队自主后撤、**不听命令**、移速 +50%、不能开火。
- 崩溃期间受到的伤害 ×1.5，且极易被全歼。
- 你可以下「收容」命令（CD 30 秒）把它拉回来，成功率 = 执行率。
- 收容成功后完整性恢复到 40，士气 -10。

> **崩的是阵线，不是人。** 一次崩盘不会直接判死刑，但会给你一段丑陋的三十秒：你的编队不听你的话往回跑，而你只能看着它在黑暗里被追。

## 8. 姿态：双轴行为树

### 8.1 两个轴

**轴一 · 姿态（它想做什么）**

| 姿态 | 行为树改写 |
|---|---|
| **进攻** | 主动找接触；会离开掩体；会拉长队形；会追到视野边缘 |
| **固守** | 不主动移动；会找最近掩体；会收缩队形；**不会追出去** |
| **机动** | 不主动接战；保持距离；会绕开敌人；输出下降 |
| **撤离** | 向撤离点移动；只还击挡路的 |

**轴二 · 交战规则（它怎么打）**

| ROE | 行为树改写 |
|---|---|
| **优先最近** | 默认 |
| **优先最危险** | 优先炮兵/重装/运输车（危险度见 10.3） |
| **只打视野内** | 不追击、不浪费弹药、不暴露位置 |
| **保命优先** | 血量 < 35% 时脱离，会放弃目标 |

**16 种组合，全部改行为，没有一个系数。**

"固守"为什么不加防御？因为它改变的是**会不会找掩体、会不会收缩、会不会追出去**。增益从行为里**涌现**，不是贴上去的。

### 8.2 切换代价

- **3 秒生效延迟**（命令要传、队形要重整），期间编队有短暂空隙（全属性 -15%）。
- 免费，但**慢**。这就是它和卡牌的分工：**姿态慢而免费，卡牌快而昂贵。**

### 8.3 默认分配

开局默认：中央=固守、左翼=机动+只打视野内、右翼=固守+保命优先。

**但默认分配应该在第一次压力测试后就被打破。** 每场战役至少要有一次"你的编队不得不改变身份"的时刻。

## 9. 注意力：你只有一个脑袋

### 9.1 池

| 阶段 | 池 | 每队均分 |
|---|---|---|
| 一（1 队） | 4 | 4.00 |
| 二（2 队） | 7 | 3.50 |
| 三（3 队） | 10 | 3.33 |

**按人头算更狠：2 人 → 5 人 → 9 人，每人分到 2.0 → 1.4 → 1.11。**

> **你越强，每个人分到的你越少。**

### 9.2 分配

- 自由分配，份额 = 该队点数 / 池。
- **重新分配有 5 秒"切换延迟"**，期间该编队执行率 -20%。
- 默认平均分。

### 9.3 效果（只影响三件事）

1. **执行率**（见第 10 节）
2. **命令延迟**
3. **自主判断质量**：份额低的编队会"保守化"——更早撤离、更少追击、更不会用技能。

## 10. 命令、延迟与执行率

### 10.1 执行率公式

```
执行率 = clamp( 30 + 0.5 × 信任 + (份额 - 1/编队数) × 100 , 15 , 95 )
```

| 情况 | 信任 | 份额 | 执行率 |
|---|---|---|---|
| 1 队，独享 | 50 | 1.00 | 55% |
| 3 队，均分 | 50 | 0.33 | 55% |
| 3 队，重点照顾 | 80 | 0.50 | 87% |
| 3 队，几乎不管 | 50 | 0.10 | 32% |

### 10.2 延迟公式

```
延迟 = 2.5 + (1 - 份额 × 编队数) × 1.5  [秒]，最低 1.5
```

| 份额 | 延迟 |
|---|---|
| 0.50（3 队时重点） | 1.75s |
| 0.33（均分） | 2.50s |
| 0.10（几乎不管） | 3.55s |

**出命令前必须显示"预计执行率"和"预计到达时间"。** 自治要是可学习的谜题，不是骰子。

### 10.3 危险度（供 ROE 使用）

```
危险度 = 预计下一轮对我方造成的伤害总量
       = 攻击 × 攻速 × 命中修正 × 剩余目标数
```

每个被标记的敌人头上有一个小小的危险度条。玩家要学会"这条最长"。

### 10.4 指令点（CP）

- 每场战斗 **6 点**，每 **45 秒 +1**，上限 10。
- 卡牌消耗 CP。
- **CP 和注意力是两条资源**：注意力是"你盯着谁"（持续），CP 是"你还能说几句话"（瞬时）。

## 11. 卡牌：例外命令

### 11.1 验收标准

> **把这张牌念出来。如果听的人只能问"加多少"，它是数值牌。**
> **如果听的人会问"那我该怎么办？"，它是策略牌。**

四条硬规矩：

1. 不许有纯 "+X%" 的牌。
2. 每张必须改一样**规则**：谁看得见什么 / 什么时候发生 / 谁被允许做什么 / 敌方哪个系统失效 / 战场形状。
3. 每张最好有**前置条件**（要看见它、要它正在蓄力、要先标记）。
4. 每张最好**拿走你另一样东西**。

### 11.2 获取：只能靠探索

- **卡组来自探索**，不来自升级。
- 战斗胜利给**补给**（修人、修机、招人），探索点给**卡牌**。
- 保底：每场战斗给 1 枚"碎片"，**3 碎片换 1 张通用牌**。保证不探索也能活。
- 牌库上限 **12 张**。满 12 张后，探索给的是"替换"机会。

### 11.3 使用

- 每场战斗开始抽 **4 张**，每张**用一次**。
- 费用 1~4 CP。
- 卡牌是"**没办法了**"时按下的东西，不是常规输出手段。

### 11.4 完整卡表

见 **附录 A**。

### 11.5 卡牌与姿态的关系

> **大部分卡牌 = 一次临时的、代价极大的标签改写。**

「不惜代价」= 15 秒内把 ROE 强行改成"无视伤亡、不撤退"。
这样两套系统是同一个系统，不是两套。

## 12. 机师与机体

### 12.1 两层角色

| 层 | 数量 | 可否重复 | 基准强度 | 呼号 | 死亡后果 |
|---|---|---|---|---|---|
| **特殊机师** | 全局唯一 | 否 | ×1.15 + 强服从面 | 呼号 + 真名 | 变成「回响」 |
| **普通机师** | 每局可招 8~12 名 | **是**（同队 ≤2） | ×1.00 + 轻服从面 | 自动生成呼号 | 进 MEMORIAL，可再招同配置 |

**没有第三层。** 层级越少，玩家越容易记住谁是谁。

**最重要的一条：普通机师也必须有名字和呼号。**

"可重复"指的是**机体配置**可以重复，不是"人没有脸"。
你死掉的每一个狙击型机师，都占 MEMORIAL 的一行，都有一句自己的遗言。

> 这条决定了这个游戏是"打仗"，还是"数人头"。

**关于"机甲，不是人"：**

- 战场上跑的是**破坏神（Juggernaut）**，不是士兵。一个三角 = 一台机甲。
- 但共和国对外宣称它们是**无人兵器**——**实际上每一台里都坐着一个孩子。**
- 所以：**视觉上是机甲，叙事上是人，痛感来自"你明明知道里面有人"。**
- 编队、伤害、死亡，全部按**机体**计算；名字、信任、服从面，全部按**机师**计算。

### 12.2 普通机师（8 种机体配置，可重复）

机体是统一型号，**差别全在兵装和机师身上**。每种只改**一个系统**，不做数值渐变。

| 机体配置 | 定位 | 关键特性 | 机师的服从面（轻） |
|---|---|---|---|
| **近接型** | 前排爆发 | 双持高周波刃；3 格内伤害 +30%，主动前压 | 固守时也会脱队前冲 |
| **射击型** | 均衡 | 多用途火炮，无特长，最稳 | 执行率 +5（最听话） |
| **狙击型** | 远程 | 长身管炮，射程 7；越远越痛；被贴身伤害 -50% | 拒绝"进攻"类命令（执行率 -15） |
| **压制型** | 中距控制 | 多管机枪；命中使目标移速 -20%，持续 3 秒 | 会一直打同一个目标（不换目标） |
| **重装型** | 承伤 | 追加装甲；HP +50%，移速 -25% | 不会后撤（崩溃阈值 +20） |
| **侦察型** | 视野 | 轻装 + 高性能传感器；感知 +3，经过留 45 秒记忆 | 被发现时强制"保命优先" |
| **电子战型** | 干扰 | 干扰吊舱：可清除敌方呼叫增援 / 共享感知 | 开干扰时不能移动 |
| **指挥型** | 通讯 | 通讯中继；所在编队执行率 +10、延迟 -0.4 秒 | 不会离开编队中心 |

**注意：没有维修型，也没有战斗中修复。**
破坏神没有战场维修能力——**这一仗挨的打，要回后方才能修。**
所以每一次交火都是有代价的，这也是这套系统里最 86 的一条。

前四种是"输出与承伤"，后四种是"改规则"。
**后四种才是有意思的**——它们直接改写第 5 节（视野）和第 10 节（执行率/延迟）的系统，而不是加一个乘区。

> **扩到 12 种为止。** 每加一种，必须回答"它让哪个系统的玩法变了"。
> 答不上来就不是新配置，是换个名字的数值。

### 12.3 特殊机师（第一版 5 名，唯一）

**强度只比普通机师高一点（×1.15），真正的价值在服从面和专属兵装。**

| 呼号 | 定位 | 服从面 | 专属能力 |
|---|---|---|---|
| **Undertaker** | 正面输出 | 优先打危险度最高；队友濒死时无视撤退/防守令 | 「集火」命令永不失败 |
| **Wehrwolf** | 指挥核心 | 队友阵亡后 10 秒内不听命令 | 所在编队执行率 +15 |
| **Gunslinger** | 远程 | 会为救队友放弃最佳射位 | 每场第一次射击必中且 ×1.5 |
| **Snow Witch** | 防御 | 队友濒死时替其承伤，且自己不能移动 | 所在编队崩溃阈值 +30 |
| **Laughing Fox** | 地形 | 不会离开自己标记的区域 | 在城区/山区造 1 个 90 秒记忆点 |

**每个特殊机师都必须有一条"用错了会害死你"的服从面。**
否则他们就只是"更强的普通机师"，而不是"人"。

### 12.4 招募、名册与重复规则

**上限：**

| 项 | 值 |
|---|---|
| 名册 | 10 名机师（满编 9 + 1 替补） |
| 每队机体 | 1~3 台 |
| **同配置普通机师 · 同一编队** | **最多 2 名** |
| 特殊机师 | 全局唯一；同一编队最多 1 名 |

**招募途径：**

| 途径 | 产出 |
|---|---|
| 休整点 | 2 选 1 的普通机师（配置随机） |
| 探索点 / 事件 | 特殊机师（每局 2~3 次机会） |
| 战场救援 | 生还的 86，配置随机，可能带伤 |

**名册满了怎么办：** 必须"让位"。被让位的人调离前线（不是处死），但本局不可再用。

> 这个决定比看起来重——**你是在选谁活着。**

**关于"允许重复"的两个平衡阀：**

1. **软上限**：同队同配置最多 2。三个狙击型会破坏队形逻辑，也会破坏地形设计。
2. **地形反制**：城区和山区贴身战多，远程堆叠在这里会被惩罚。

**重复必须是优势，也必须是风险。**

### 12.5 服从面怎么写（设计规则）

**机师特性不是"随机捣乱"，是"有形状的工具"。**

每个服从面必须写成三行：

1. **目标选择规则**（它优先打谁）
2. **抗令条件**（满足什么才不听）
3. **隐藏好处**（顺着它用时给的补偿）

第 3 条最重要——**特性必须有"顺着他用"的正反馈，否则就是纯惩罚**，玩家只会讨厌这个人。

**它和执行率的接口（这是核心）：**

```
最终执行率 = 基础执行率（见 10.1） × 服从面修正
```

| 这条命令和它的规则 | 修正 |
|---|---|
| 符合（比如让 Undertaker 打最危险的目标） | **×1.15** |
| 无关 | ×1.00 |
| 违反（比如让它撤退） | **×0.60**，且有概率直接拒绝 |

**这就是为什么"了解你的人"比"更强的数值"重要**：
你下的每一条命令，都要先想一遍"他会怎么听"。

**模板，一行写完：**

> 「呼号」目标：\_\_\_；抗令：\_\_\_；好处：\_\_\_。

### 12.6 信任

- 初始 **40~65**（有名字的角色更高），范围 0~100。
- 增减：

| 事件 | 信任 |
|---|---|
| 听完一次通讯（不打断） | +2 |
| 兑现一个承诺 | +5 |
| 告诉他们真相 | -10 ~ +10（看人） |
| 下令"不惜代价" | -8 |
| 放弃回收大脑 | -5 |
| 有人在他们的掩护下活下来 | +3 |

### 12.7 死亡

- 永久死亡。名字不重复。
- **死亡发生在链路上**：画面不暂停，你听到最后一句通讯，然后那条波形变成噪声，永远留在底部。

### 12.8 大脑运输（核心机制）

阵亡后：

1. 自动生成一个**回收任务**，60~90 秒倒计时。
2. 运输车从最近的地图边缘出现，低速、低威胁，但**会呼叫护卫**。
3. 你必须**抽走一个编队**去拦截。
4. **救不救是自由的**，但代价要明确：

| 结果 | 后果 |
|---|---|
| 拦截成功 | 保住大脑；"归葬"→ 全队信任 +5 |
| 主动放弃 | 信任 -5；该单位在战役后段以**「回响」**形式回归 |
| 来不及 | 同放弃，且你听到运输车离开的声音 |

**「回响」**：以你死掉的机师为原型生成的敌方机体——同样的名字、同样的呼号、同样的战斗方式，但站在对面。**并且它知道你的习惯**：你爱把侦察型放哪、撤退走哪条路。

于是敌方的难度成长不需要额外系统，它来自你失去的人。

> **你不是在选择救不救他，你是在选择要不要让他被用。**

### 12.9 摘面罩（情感核心）

- 战斗中**永远没有立绘**。只有呼号、血条、通讯波形。
- 信任 ≥ 80 且该单位在战役中存活 → **结算界面他主动摘下面罩**，给你一张立绘。
- **死了就永远没有这张图。**

这一条同时解决：情感重量、长线收集动机、"为什么要在乎这些棋子"。

## 13. 敌人：军团与意图

### 13.1 军团是 AI，所以它有计划

**你打的不是刷怪表，是敌方的一个作战计划。**

每场遭遇，敌方从意图库里抽一个意图，并且**提前 10~15 秒有"蛛丝"**。

| 意图 | 蛛丝（玩家能观察到什么） | 压力特征 | 应对 |
|---|---|---|---|
| **钳形** | 两个不相邻方位同时亮起低亮度方位楔 | 两翼同时升温 | 放弃一边，收窄正面 |
| **铁砧** | 正面持续稳定强信号 + 侧翼无线电静默 | 正面钉住，侧翼重击 | 中央改固守，侧翼改撤离 |
| **蜂群** | 方位楔数量多但都很宽、很暗，全方位均匀 | 周长压力 | 合流，不要分兵 |
| **灯塔** | 某个方位有稳定的强信号且不动 | 远程炮兵 + 观察哨 | 必须移动，不能固守 |
| **静默** | **什么都没有** | 未知 | 提前点亮，准备接战 |
| **漏斗** | 缺口太干净了 | 假缺口 | 交叉验证再进 |

> **"静默"和"缺口太干净"是这个游戏最吓人的两件事。**

### 13.2 军团机体（第一版 6 型）

**军团是无人兵器——金属、黑色、没有驾驶舱。** 它们不认识恐惧，只认识命令。

| 型 | 作用 | 危险度 | 备注 |
|---|---|---|---|
| **步兵型** | 蜂群、消耗 | 低 | 数量最多，死多少都无所谓 |
| **装甲型** | 正面推进 | 中 | 厚装甲，蓄力冲击波 |
| **炮击型** | 超远程压制 | **高** | 需要观察者指引 |
| **电子战型** | 压缩我方感知半径；**清除一片侦察记忆** | 中 | 最讨厌的一型 |
| **回收型** | 运走阵亡者的脑髓 | 低（但绝不能放过） | 大脑被运走 → 变成回响 |
| **牧羊人** | Boss / 回响，指挥其他单位 | 极高 | **脑髓来自你死掉的 86** |

**军团最可怕的地方，不是它们强，是它们不会崩。**

你的部队完整性归零会失控、会逃跑、会不听命令。
它们不会——**它们只会继续往前，直到被拆成零件。**

> 这个不对称，比任何数值都更能说明"你带的是人，它们带的是机器"。

### 13.3 军团的学习

- 军团会**记住你最常用的指令**，在下一场针对性反制（你总用掩护，它就带穿甲弹）。
- 回响单位会携带**你上一次的打法**。
- 这条让"重复同一套打法"逐渐失效，是肉鸽重玩性的来源。

## 14. 战役模式：换目标函数，不换地图

| 模式 | 赢的条件 | 输的条件 | 为什么要分兵 |
|---|---|---|---|
| **围剿** | 撑到撤离窗口 / 突围 | 全灭 | 守多个方向 |
| **防守** | 守住 N 分钟 / 守住建筑 | 丢失据点 | 守多个入口 |
| **进攻** | 摧毁目标 | 时间耗尽 | 多路推进 |
| **偷袭** | 在警报前完成 | 被发现 | 佯动 + 主攻 |
| **回收** | 抢回大脑 / 物资 | 运输车离开 | 一路拦截、一路掩护 |

同一套系统、同一张地图，只换目标函数和意图库。**这是最省工也最出效果的做法。**

## 15. 大地图、探索与时间压力

### 15.1 结构

- 一张约 **60×40 格**的战役地图（战略尺度），大部分是黑的。
- 分成 3 段战线，每段结尾一个高潮。
- 地图上有：遭遇点、探索点、休整点、撤离区。

### 15.2 探索点

| 地点 | 产出 | 风险 |
|---|---|---|
| 废墟 / 坠机点 | **卡牌**（60%） | 需要抽走一个编队 |
| 前哨站 | 补给、维修（30%） | 可能已被占领 |
| 城市 | 情报、生还者（10%） | 视野被建筑切碎，最易遭伏 |
| 军团节点 | 战役目标 + 稀有卡 | 打它就是暴露自己 |

**每次探索消耗 30~60 秒真实时间 + 1 个编队。**

### 15.3 压力系统（P）

全局压力 0~100：

| 来源 | ΔP |
|---|---|
| 时间流逝 | +2 / 30 秒 |
| 每次探索 | +8~15 |
| 每次遭遇战胜利 | +5 |
| 休整 | -20 |

| 阈值 | 后果 |
|---|---|
| P ≥ 60 | 敌方规模 ×1.2 |
| P ≥ 85 | 每场遭遇额外一波 |
| P = 100 | 战役失败（被合围） |

**核心张力**：

> 我现在抽走左翼去搜那个废墟，中央就只剩两个编队顶正面，而中央的援军还有 90 秒到。

**"贪"必须是一个具体的、可计算的决定**，而不是"要不要多打一层"。

### 15.4 舔包

- 战场清空后，**区域变为可搜索**。
- 搜索时**战斗仍在继续**（增援在来）。
- 你每多待 30 秒，P +4。

### 15.5 休整点

每段战线结束后出现。**不消耗战场时间**，压力 -20。

每次休整**三选一**：

| 选项 | 效果 |
|---|---|
| **维修** | 全员 +30 HP；修复一台受损机体 |
| **招募** | 从 2 名候选人里选 1 名（名册未满时） |
| **改牌** | 删 1 张牌 / 把 2 张碎片换 1 张 |

选完之后，**可以让每个人说一句话**。这不是功能，是信任的来源：听完 +2。

> 休整点是这个游戏里唯一"不紧张"的地方。**所以它必须很短，而且必须有点难过。**

## 16. 成长与上限

### 16.1 四条成长轴（不超过四条）

1. **人**（名册扩大）——最重
   - 普通机师靠招募和救援，**可重复、可损失、可补员**
   - 特殊机师靠探索和事件，**一次性、不可替代**
   - 这是整个成长体系里唯一的"量"与"质"双轨
2. **指挥权**（编队上限 1→2→3）——最稀有
3. **知识**（卡牌，靠探索）
4. **信任**（执行率，靠相处）

**装备/改造近乎不做**，或只做"一次性、不可叠加"的改造。一旦有随机词条，玩家会开始刷装备而不是琢磨战术。

### 16.2 三阶段解锁

| 阶段 | 触发 | 解锁 |
|---|---|---|
| 一 | 开局 | 点亮、姿态、移动 |
| 二 | 第一次回收任务（**被迫**） | **拆分编队**、第一批卡牌 |
| 三 | 完成第二段战线 | 第三编队、大战役目标 |

**第一次拆分不该是奖励，该是被迫。** 让系统在"你必须分出一个人"的危机里把按钮交给你——你学到的不是"我变强了"，是"**分兵是要用别人的命换的**"。

### 16.3 名词表

| 项 | 上限 |
|---|---|
| 编队 | 3 |
| 每队机体 | 3 |
| **每队同配置普通机师** | **2** |
| **特殊机师** | **全局唯一** |
| 名册 | 10（满编 9 + 1 替补） |
| 牌库 | 12 |

### 16.4 后期不是变强，是变准

上限是死的，所以游戏的后三分之一，成长曲线从"数值"切换成了"技术"：

> 你已经不能更强了，你只能打得更精确——而精确，也救不了所有人。

## 17. 战斗状态机

### 17.1 编队状态

```
IDLE ──接触──> ENGAGE ──完整性<30──> SHAKEN ──完整性=0──> BROKEN
                  │                                          │
                  └──命令"撤离"──> RETREAT                  └──"收容"──> RECOVER ──> IDLE
```

- `SHAKEN`：完整性 <30，开始动摇，移速 -20%，输出 -20%，信任下降。
- `BROKEN`：崩溃，不听命令，回撤，易被歼灭。
- `RECOVER`：收容中，3 秒，期间不能开火。

### 17.2 单位状态

```
ALIVE ──HP<35%──> WOUNDED ──HP=0──> DOWN ──回收窗口 60~90s──> GONE / ECHO
```

- `DOWN`：倒地但大脑还在。**这时候你还来得及。**
- `GONE`：大脑被运走。
- `ECHO`：下一场以敌方身份回归。

### 17.3 一场遭遇的节奏（5 分钟弧）

```
0:00  进入 —— 编队周围一圈可见，外面全黑，几道很淡的方位楔
0:30  试探 —— 蛛丝出现，第一次点亮，判断意图，第一批敌人进入可见区
1:30  合围 —— 可见区里已经打成一团，环收紧，撤离窗口出现并倒计时
3:00  抉择 —— 目标完成度 vs 走廊闭合
4:30  走 / 全灭 / 硬撑
```

### 17.4 撤离

- 地图边缘有一个**撤离区**（圆，半径 6 格）。
- 撤离窗口开启后，进入 **60~90 秒倒计时**（随压力缩短）。
- 编队必须**开到撤离区里**才算走成——路上会被人追。
- **撤离中被打断**（编队崩溃 / 撤离区被占）→ 撤离失败，人还在战场上。
- 成功撤离 = 战役判负，但**名册完整保留**，进入下一局。

> 撤退不是菜单，是地图上的一个地方。**想走，就得放弃阵地。**

### 17.5 一局结束的三种方式

| 结局 | 条件 | 后果 |
|---|---|---|
| **战役胜利** | 完成 3 段战线目标 | 最优；解锁下一层 |
| **主动撤退** | 全队进入撤离区 | 判负，但保住人；**下一局继承名册** |
| **全灭** | 所有编队 DOWN 且无法回收 | 最差；但卡组与真相碎片保留 |

## 19. 前 10 分钟脚本

这是一份"如果做对了，玩家会经历什么"的验收稿。

**0:00 — 开局**
两个三角，站在一小片被照亮的地形里。网格若隐若现，脚下是城市废墟的轮廓。
再往外是纯黑。无线电底噪。一个人说："中尉，我看不见它。"
HUD 上两条波形，微微起伏。

> **注意：开局不是全黑屏。是"两个人在一小块光里，光外面全是黑"。**
> 这个构图要贯穿全游戏。

**0:20 — 移动**
玩家用 WASD 试探着推镜头，滚轮拉远。
编队外侧慢慢浮出**一道很淡的弧形楔**，在东南方，一动不动。
那里**什么都没有**——只有一个方向。玩家第一次意识到"外面有东西，但我看不见"。

**0:50 — 第一次点亮**
那道弧开始变亮、变宽，声音也近了。
玩家右键点向那个方向。
一圈光晕炸开，6 秒内看清：4 台军团，正朝编队来。
**从"一道弧"变成"四个方块"，拖尾拉出四条红线。**
音效：低频轰鸣突然变近。

**1:10 — 第一次下令**
左键选中编队，点最危险的那台。
屏幕上浮出：`集火 · 执行率 58% · 到达 2.5s`。
玩家盯着那 2.5 秒的倒计时。

**1:40 — 第一次真正的混战**
第二波到了。视野里同时有 8 台方块在动，三角在转身、在开火、拖尾和弹道糊成一片。
**玩家第一次觉得"这画面真好看"——然后发现自己顾不上指挥了。**

**1:55 — 第一次偷袭**
第三台从侧后摸进来——它的方位楔被另外两道的亮光盖住了。
第一击 ×2.0，一个人掉了 40 血，画面白闪一下。
玩家第一次感到"我看漏了一个方向"。

**2:20 — 第一次改姿态**
玩家把编队改成「固守」+「只打视野内」。
它开始找掩体、收缩、不再追。
血掉得慢了。玩家明白了：**姿态不是 buff，是行为。**

**4:00 — 第一次崩**
完整性归零，编队开始往回跑，不听命令。
玩家听到她在喊"我控制不住了"。
30 秒后收容成功，剩 1 个人，满身是伤。

**7:00 — 第一次探索**
玩家拉远镜头，看到远处有一块废墟，旁边浮着一枚很淡的菱形标记。
他做了一个决定：把人开过去。
压力条开始涨。

**8:10 — 第一次收编**
废墟里找到一台还在动的破坏神。驾驶舱打开，里面是个孩子。
系统给了她一个自动生成的呼号：`Sparrow-04`。她的兵装是狙击型。
她比 Undertaker 弱一截，还有一个不肯打贴脸目标的小毛病。
但她有名字、有呼号、有遗言。
**玩家第一次意识到：共和国对外说这是无人兵器，可刚才那台里有人在说话。**

**9:30 — 第一次分兵**
回收型从北面来。60 秒。
系统在这一刻把「拆分」按钮交给他——不是奖励，是**唯一的选择**。
他分出 Sparrow-04 一台去拦。
那一分钟里，他不停地在这两个编队之间跳镜头。

**10:00 — 结束**
他拦下了。大脑保住了。全队信任 +5。
屏幕上多了一条新的波形。
他学到的第一课是：**分兵是要用别人的命换的。**

## 20. 风险与对策

| # | 风险 | 表现 | 对策 |
|---|---|---|---|
| 1 | **打地鼠化** | 只在被打时点亮 | 「提前点亮 = 伏击先手」奖励预判 |
| 2 | **迷雾随机杀人** | 玩家觉得死得冤 | 偷袭只在"完全未发现"时触发，且必须有视觉预警 |
| 3 | **认知过载** | 3 队管不过来 | 焦点编队 + 注意力边际递减 + 压到 3 队 |
| 4 | **挫败感** | 死一次 = 白玩一小时 | 撤离保留队伍；战役失败 ≠ 游戏结束 |
| 5 | **卡牌取代指挥** | 玩家觉得靠牌赢 | 手牌 4 张、费用紧张、大部分牌要前置条件 |
| 6 | **数值化** | 出现 "+30% 防御" | 用第 11.1 节的尺子逐张量 |
| 7 | **紧张感流失** | 拉远就全看见了 | 远视角只有密度与流向，没有兵种 |
| 8 | **探索变随机打断** | 每搜一次跳一波怪 | 探索的代价只做"时间"，不做随机遭遇 |
| 9 | **三个编队趋同** | 三队变成三个一样的队 | 每个方位的地形与压力天然不同 |
| 10 | **角色特性变纯惩罚** | 玩家讨厌不听话的人 | 每个特性配一条"顺着他用"的正反馈 |

## 21. MVP

**只验证乐趣假设 A（被服从 / 被误解）和 B（来不及）。**

### 21.1 灰盒清单

1. 一张 40×40 的黑场地，六边形网格（装饰）+ 三种地形色块
2. 相机：WASD + 滚轮（0.35x ~ 2.0x）
3. 迷雾：格网实现 + 5 秒渐隐 + 残影；**雾里不画任何东西，雾外必须画满**
4. **方位提示：弧形楔（宽度/亮度/抖动）+ 1~2 秒延迟 + 静止衰减**
5. 1 个编队、2 个角色、扇形视觉
6. 右键点亮（CD + 半径衰减 + 标记 25 秒）
7. 标记增伤 ×1.4、偷袭 ×2.0
8. 自动战斗：找目标、开火、移动
9. **命令系统：执行率预览 + 在途倒计时 + 按执行率决定成败**
10. 姿态：4 × 4（先做 2 × 2 也行）
11. 左键：选编队 → 点敌人集火 / 点地面移动
12. 3 种敌人（步行 / 重装 / 炮兵）+ 2 种意图（钳形 / 静默）
13. 崩溃 + 收容
14. **画面验收：一场遭遇里，视野内至少要同时出现 8 台敌人在动，拖尾连成线**
15. 无卡牌、无大地图、无肉鸽层

### 21.2 验收问题

> **玩家下完令，会不会盯着那个编队等？等到之后，会不会骂一句？**

会等、会骂，这游戏就成了。

不会等，说明命令没有重量——先调执行率公式和延迟，**不要再加系统**。
不会骂，说明执行太顺了——把信任初始值调低，或者让失败更有戏。

### B.1 迷雾实现建议

- 逻辑格：32px。存三张表：`visible`（bit）/ `remembered`（**带过期时间的 byte**）/ `marked`（bit）。
- **`remembered` 每格存一个"剩余秒数"**（0~45），侦察兵经过时刷新为 45，每帧 -dt。
  渲染时用 `remaining/45` 直接当亮度系数——**褪色是数据，不是动画。**
- **渲染铁律（两头都要）：`visible` 为 0 的格子里，一个敌人都不许画；`visible` 为 1 的格子里，必须画满。**
  雾只有"全有"和"全无"——没有半透明、没有轮廓、没有暗色剪影。
- 渲染：不做逐像素遮罩。用**加法混合的软圆光晕贴图**叠在暗底上。
- "渐隐"不是改 alpha，而是让 `visible` 逐帧收缩半径（5 秒内从 R 收到 0）。
- **方位楔单独走一条渲染管线**：它不属于 `visible`，它属于"感知算法"。
  每帧对每个编队做一次方位统计（把 15 格内的敌人按方位角分桶），输出 1~3 个楔。
  **楔只读方位和距离，不读敌人实体**——这样即使整个军团系统是隐藏的，楔也能画出来。
- 性能红线：**一台 = 一个方块，不做抽象合并**（合并会毁掉"铺天盖地"的观感）。
  靠"只渲染 `visible` 格子里的单位"扛性能：视野外不渲染、不跑细节 AI。
  全场军团容量 ≤ 400，视野内同时渲染 ≤ 80。
